Project mappings

Which project applies on which site. Patterns kept in this browser are read first, then your instance’s, and the first that matches wins. * matches within one part of the path, ** across parts. The branch, optional, is the one deployed at those addresses (a staging site on develop, say): Tested elements then shows what that branch’s tests reach.

From your Piwi instance

Set in each project’s settings, under Browser extension URLs, and read each time this page opens.

Add a site

Adds the pattern to a project on your instance, for everyone who connects to it. It takes a role that can edit the project.

Send to editor

In VS Code or a JetBrains IDE with the Piwi extension, run “Piwi: Pair with Piwi Picker” and paste the address it copies here. Picked locators and recorded steps can then be sent to that editor, on this computer only, and are inserted at its cursor.

Desktop app

Optional. Paired with the Piwi Dashboard desktop app, Replay can ask it to run a bug report with Playwright in your project. Copy the address and token from the app’s Setup page, under Connect Piwi Picker.

Only used from this page: the API key never reaches a web page’s scripts. Recorded steps go nowhere unless you copy them, download them or send them to your paired editor. Connecting downloads your projects’ URL patterns, each mapped project’s function catalog and the elements its tests reach; adding a site sends only its pattern.
